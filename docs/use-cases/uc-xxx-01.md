# UC-FIT-01. Записаться на групповое занятие

| Поле | Значение |
|---|---|
| Основное лицо | Клиент. |
| Другие действующие лица | CRM клуба, сервис уведомлений. |
| Предусловия | У клиента есть действующий абонемент. |

## Основной сценарий

1. Клиент выбирает запись на групповое занятие.
2. Система проверяет возможность записи на данную тренировку.
3. Клиент подтверждает бронирование места на групповой тренировке.
4. Система фиксирует новую успешную запись клиента.

## Альтернативные сценарии

**2а. Свободных мест нет**

1. Система сообщает об отсутствии свободных мест.
2. Система предлагает вступить в лист ожидания.
3. При согласии запускается сценарий «Вступление в лист ожидания».
4. При отказе сценарий завершён без изменений.

**2б. Запись еще не открыта**

1. Система определяет, что до занятия осталось больше 7 суток.
2. Система сообщает дату и время открытия записи.
3. Завершение сценария без записи.

**2в. Клиент уже записан**

1. Система находит действующую запись клиента на выбранное занятие.
2. Система показывает сообщение «Вы уже записаны».
3. Сценарий завершен, доп. место не занимается.

**2г. Абонемент не позволяет посетить занятие**

1. CRM выдаёт информацию о неподходящем абонементе.
2. Система извещает причину недоступности.
3. Сценарий завершён без создания записи.

## Постусловия

При успехе:

1. Для клиента существует одна запись на конкретное занятие.
2. Запись доступна для отмены и записи клиенту.
3. При записи занятие с абонемента не списывается.

При неуспехе:

1. Новая запись на занятие не создана.
