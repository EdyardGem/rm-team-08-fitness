# UC-FIT-02. Вступить в лист ожидания и получить освободившееся место

| Поле | Значение |
|---|---|
| Основное лицо | Клиент. |
| Другие действующие лица | Сервис уведомлений. |
| Предусловия | У клиента есть действующий абонемент. На выбранное занятие нет свободных мест. |

## Основной сценарий

1. Клиент подтверждает вступление в лист ожидания на выбранное занятие.
2. Система добавляет клиента в лист ожидания и уведомляет его об этом.
3. После отмены записи другим клиентом система определяет, что на занятии освободилось место.
4. Система определяет первого клиента в листе ожидания.
5. Система автоматически записывает этого клиента на занятие и исключает его из листа ожидания.
6. Система отправляет клиенту уведомление об успешной записи.

## Постусловия

1. Клиент записан на занятие.
2. Клиент исключён из листа ожидания на это занятие.
3. Клиенту отправлено уведомление об успешной записи.
4. При записи занятие с абонемента не списывается.
