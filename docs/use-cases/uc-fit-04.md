# UC-FIT-04. Отмена группового занятия

| Поле                    | Значение                                                             |
| ----------------------- | -------------------------------------------------------------------- |
| Основное лицо           | Клиент                                                               |
| Другие действующие лица | CRM клуба, сервис уведомления                                        |
| Предусловия             | У клиента есть действующий абонемент и действующая запись на занятие |
## Основной сценарий
1. Клиент выбирает тренировку, которую хочет отменить.
2. Система проверяет возможность отмены на выбранную тренировку.
3. Клиент подтверждает отмену занятия.
4. Система фиксирует успешную отмену занятий.
5. Система уведомляет клиента о том, что запись на занятие отменена.
6. С абонемента клиента не списывается оплаченное занятие.

## Альтернативные сценарии 
**2а. Клиент хочет отменить занятие менее чем за 4 часа до начала занятия**
1. Система определяет, что до занятия осталось менее 4 часов.
2. Система сообщает клиенту, что отменить занятие невозможно.
3. Завершение сценария без отмены занятия.

**3а Клиент не подтверждает отмену занятия в течение 5 минут**
1. Система выводит клиенту подтверждение об отмене тренировки.
2. Система не отменяет занятие, если клиент не подтвердил отмену тренировки или если сервер приложения не получил подтверждение
3. Завершение сценария без отмены занятия.

## Постусловия
При успехе:
1. Клиент удален со списка записанных на тренировку.
2. С абонемента клиента не будет списано занятие.

При неуспехе:
1. Клиенту не удалось отменить запись на занятие.
2. С абонемента клиента будет списано занятие, при условии, что оно будет проведено.
