# UC-FIT-03. Учесть посещение группового занятия

| Поле | Значение |
|---|---|
| Основное лицо | Клиент. |
| Другие действующие лица | Система контроля доступа (турникет), CRM клуба. |
| Предусловия | У клиента есть действующая запись на занятие и действующий абонемент. |

## Основной сценарий

1. Клиент проходит через турникет.
2. Система контроля доступа передаёт событие прохода клиента в систему записи.
3. Система записи определяет клиента и соответствующее занятие, на которое он записан.
4. Система записи передаёт в CRM клуба запрос на списание одного занятия с абонемента клиента.
5. CRM клуба списывает одно занятие и подтверждает выполнение операции.
6. Система записи фиксирует посещение занятия клиентом.

## Постусловия

1. Посещение занятия клиентом зафиксировано.
2. С абонемента клиента списано одно занятие.
3. Событие прохода отмечено как обработанное.
