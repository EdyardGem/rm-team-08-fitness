# Глоссарий

**Занятие** — групповая тренировка, проводимая в определённом клубе по установленному расписанию и имеющая ограниченное количество мест.

**Абонемент** — право клиента на посещение фиксированного количества занятий в течение установленного срока действия, учитываемое в CRM-системе.

**Запись** — резервирование места на конкретном занятии за определённым клиентом.

**Лист ожидания** — список клиентов, желающих попасть на занятие при отсутствии свободных мест. Используется для автоматической записи при освобождении места.

**Неявка** — отсутствие клиента на занятии, на которое у него сохранилась действующая запись.

**Сгорание занятия** — списание одного занятия с абонемента клиента при отмене записи менее чем за 4 часа до начала тренировки.
