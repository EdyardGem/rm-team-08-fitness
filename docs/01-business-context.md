# Фитнес-клуб: запись на групповые тренировки (приложение)

## 1. Бизнес-контекст

Цель: повышение эффективности использования мест на групповых тренировках путем внедрения приложения для записи, управления ею, а также реализации очереди путем внедрения листа ожидания.

За 3 месяца ожидается довести среднюю заполняемость до 85%, а неявка должна снизиться вдвое по сравнению с текущими значениями.

## 2. Проблема / боль

Запись через администратора или по телефону не обеспечивает эффективного распределения мест на наиболее популярных занятиях.

Клиенты не могут записаться в результате переполнения, при этом до 30% записавшихся пропускают занятие, из-за чего места остаются незанятыми.

## 3. Стейкхолдеры

- Заказчик — повысить заполняемость занятий.
- Клиенты фитнес-клуба — удобная запись и возможность попасть на популярные занятия.
- Администраторы — снизить загруженность администратора при записи.
- Тренеры — планирование проведения занятий.
- Поставщик CRM — обеспечить корректное взаимодействие приложения с данными.

## 4. Бизнес-правила

1. Запись на занятие открывается за 7 дней.
2. Отменить занятие возможно не позднее чем за 4 часа до занятия. В ином случае занятие сгорает.
3. Есть лист ожидания для эффективного использования мест.
4. Занятие списывается с клиента при прохождении через турникет.
