# Роли пользователей системы

## 1. Клиент

### Цели
- Записаться на тренировку.
- Отменить занятие.
- Встать в лист ожидания.

### Ключевые действия
- Запись на занятие.
- Отмена занятия.
- Вступление в лист ожидания на конкретную тренировку.

### Права доступа
- Просмотр своего расписания тренировок.
- Просмотр всех доступных тренировок.

## 2. Тренер

### Цели
- Провести тренировку в удобное для всех время и с оптимальным составом.
- Проведение занятий и контроль посещаемости и прогресса.

### Ключевые действия
- Согласовать время тренировок с администратором.
- Просмотреть записавшихся клиентов к нему на тренировку.

### Права доступа
- Просмотр общего расписания тренировок.
- Просмотр записавшихся к нему на тренировку.

## 3. Администратор

### Цели
- Составление графика в фитнес-клубе с учётом требований.
- Корректное списание занятий у клиента при проходе через турникет.

### Ключевые действия
- Замена тренера.
- Редактирование расписания.
- Регистрировать новых тренеров.
- Добавление тренеров.
- Назначение тренеров на тренировки.

### Права доступа
- Просмотр расписания тренировок.
- Редактирование расписания тренировок.
- Удаление тренеров.
- Замена тренера.
- Отмена тренировки.
- Добавление тренера.
- Удаление тренера.
