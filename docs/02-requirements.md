# Требования к системе записи на групповые занятия

## 1. Бизнес-требования (BR)

- **BR-01.** За 3 месяца повысить среднюю заполняемость групповых занятий сети «Энергия» до 85%.
- **BR-02.** За 3 месяца сократить количество неявок на групповые занятия вдвое относительно исходного уровня.

## 2. Пользовательские требования (UR)

- **UR-01.** Клиент должен иметь возможность самостоятельно управлять своей записью на выбранное занятие. (BR-01, BR-02)
- **UR-02.** Клиент должен иметь возможность получать уведомления об освобождении места через лист ожидания. (BR-01)
- **UR-03.** Тренер должен иметь возможность просматривать список клиентов, записанных на его занятие. (BR-01)
- **UR-04.** Администратор должен иметь возможность назначать или изменять тренера, проводящего занятие. (BR-01)

## 3. Функциональные требования (FR)

### 3.1. Расписание и запись

- **FR-01.1.** Система должна отображать расписание занятий выбранного клуба. (UR-01)
- **FR-01.2.** Система должна позволять клиенту записаться на занятие при наличии свободных мест, начиная за 7 дней до его проведения. (UR-01)

### 3.2. Отмена записи

- **FR-02.1.** Система должна позволять клиенту отменять действующую запись на занятие. (UR-01)
- **FR-02.2.** Если клиент отменяет запись менее чем за 4 часа до начала занятия, система должна списывать одно занятие с его абонемента. (UR-01)

### 3.3. Лист ожидания

- **FR-03.1.** При отсутствии свободных мест система должна предоставлять клиенту возможность встать в лист ожидания с соответствующим уведомлением. (UR-02)
- **FR-03.2.** При освобождении места система должна уведомлять первого клиента из листа ожидания о возможности записаться на занятие. (UR-02)

### 3.4. Учет посещений

- **FR-04.** При получении события прохода клиента через турникет система должна списывать соответствующее занятие с его абонемента. (UR-01)

### 3.5. Управление занятиями

- **FR-05.** Система должна отображать тренеру список клиентов с действующей записью на его занятие. (UR-03)
- **FR-06.** Система должна позволять администратору изменять назначенного тренера для занятия. (UR-04)

## 4. Нефункциональные требования (NFR)

- **NFR-01.** При оформлении записи система должна проверять, что количество записанных клиентов не превышает установленный лимит мест.
- **NFR-02.** Повторная обработка одного и того же события прохода через турникет не должна приводить к повторному списанию занятия.

## 5. Ограничения (CON)

- **CON-01.** Система записи распространяется на групповые занятия трех клубов сети «Энергия».
- **CON-02.** MVP не включает продажу абонементов, планы питания и тренировок.

## 6. Требования к интеграции (EI)

- **EI-01.** Интерфейс с системой контроля доступа должен обеспечивать получение событий прохода клиентов через турникет. (FR-04)
